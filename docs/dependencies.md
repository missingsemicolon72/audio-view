# Dependencies

Every dependency, with its licence and why it is here (CLAUDE.md §9). Licences must be verified with `cargo deny` (Rust) or a license-checker (npm) the first time a dependency is used; add the date of that check.
Allowed: MIT, Apache-2.0, BSD-2/3-Clause, ISC, Zlib, CC0-1.0, BSL-1.0, Unicode licences. MPL-2.0 only as an unmodified dependency. Not allowed: GPL, AGPL, LGPL, CC BY-NC, unclear terms.
