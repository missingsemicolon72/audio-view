# Architecture Decision Records

One short file per notable decision: `NNN-title.md` (zero-padded, for example `001-ipc-payload-format.md`).
Locked decisions live in CLAUDE.md §3; an ADR records the reasoning behind a choice made inside that frame.

## Template

```markdown
# NNN. Title

- Status: proposed | accepted | superseded by NNN
- Date: YYYY-MM-DD

## Context
What forced a decision? What constraints apply (guardrails, budgets, licences)?

## Decision
What we chose, in one or two sentences.

## Consequences
What gets easier, what gets harder, what we will need to revisit.
```
